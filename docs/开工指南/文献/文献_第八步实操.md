# 文献第八步：细化选题、评分与差异表（节点 5）

> 本文件保留开发阶段记录。当前状态、复现命令和未完成事项请以 [交接清单](文献_交接清单.md) 为准；全部文档见 [文档目录](README.md)。

本步骤把已归档的阅读摘要变成可交给后续阶段的结构化选题草稿。模拟流程通过不代表研究结论成立。

## 目的与原理

1. refine：强档模型输入任务配置、预算、阅读摘要和证据条目，输出 SelectedIdea。代码固定任务路径、预算、数据来源和产物链接。
2. score：五维评分均为严格整数 1–5，并检查引用真实存在。risk 越高表示风险越大。证据为空、只有论文 ID、摘要、推断或冲突时保留待核验标记。
3. gap_table：模型输出结构化单元格；代码检查行覆盖与同篇论文证据，再渲染英文 Markdown。没有证据的格子统一显示 To verify。
4. 调用前保存 started 记录；成功结果固定输入哈希，重入不重复调用。中断状态必须人工核对费用；无效回复最多再修复一次。
5. LoRA 示例仍绑定 tasks/smoke。它没有训练数据，只有调试指标；输出必须保留 TASK FIT TO VERIFY，不能声称训练已跑通。

## 文件与作用

- airesearcher/stages/idea/evidence.py：读取固定证据、检查引用身份和证据强度。
- airesearcher/stages/idea/selection.py：任务约束、选题、评分、差异表和有界修复。
- airesearcher/stages/idea/models.py：新增严格评分、选题及表格内部输出结构，保持共享数据模型不变。
- airesearcher/stages/idea/render.py：确定性英文比较表渲染。
- airesearcher/stages/idea/prompts/refine.v1.md：选题与可证伪假设。
- airesearcher/stages/idea/prompts/score.v1.md：五维评分锚点与证据要求。
- airesearcher/stages/idea/prompts/gap_table.v1.md：逐篇、逐格比较约束。
- airesearcher/stages/idea/stage.py：接入新阶段及开发检查点。
- scripts/literature/demo.py：明确标记的模拟输出与节点演示。
- tests/test_idea_selection.py：非法指标、虚构引用、证据降级、有界修复和恢复实验。
- 已有 tests/test_idea_*.py：显式停在原 merge 节点，保留原阶段测试的范围。
- docs/详细设计/2_文献查阅与选题_详细设计.md：实现进度记录。

节点 5 只承诺结构约束及离线行为验证。真实模型质量、最终文档及审批修订属于后续验证。
