## 本轮目的与边界

流程：parse → plan_queries → search → screen → fulltext（本轮完成）→ read（待实现）。
本轮只准备阅读材料，不生成阅读卡、论文结论或最终选题。
模型回复和相关性评分仍是模拟；PDF 下载和解析可以是真实的，是否联网由 --fetch-fulltext 明确控制。

## 1. 准备解析依赖

目的：按详细设计使用 pypdf 提取 PDF 文本。

```powershell

python -m pip install -e ".[dev]"
```

只需补装解析包时也可运行 `python -m pip install "pypdf>=6,<7"`。

## 2. 只处理入选的 arXiv 论文

目的：控制下载范围，使资源消耗对应筛选结果。

- 只处理 selected_for_reading=true 的记录。
- 有效 arXiv ID 才能构造下载 URL；非 arXiv 论文保留摘要/元数据。
- 请求前检查域名权限；沿用 3 秒间隔和同域串行。
- 重定向逐步记录，只接受标准 HTTPS 端口的 arxiv.org/export.arxiv.org，无用户信息的 URL。
- 单次响应大小最多 25 MiB，使用流式读取；不会先无限制下载再检查大小。
- 下载、HTTP、解析失败均记录原因并保留摘要，不编造正文。

这一步由 fulltext.py 和 sources/http.py 实现。

## 3. 提取和截取文本

目的：为下一轮阅读员提供真实、长度受控、有页码依据的输入。

- pypdf 解析文本，添加 [p.1]、[p.2] 等页码标记。
- 解析成功且有有效文本后才标 access_level=full_text。
- 单文档最多 150 页，单页内容流和总文本量另有检查；不执行 OCR。
- 短于 12,000 词的文档保留全部提取文本。
- 更长文档优先选摘要、引言最后两段、方法、实验/结果、局限和结论，保留子章节。
- 兼容小型大写字体提取为 I NTRODUCTION 等带空格标题的情况。
- 章节匹配过少时回退到限定词数的原始文本，并在记录中注明策略。

章节定位是启发式，表格、公式和多栏文本可能错序，后续阅读引用需要对照原 PDF。
全文获取成功不意味着模型已读过全部内容；fulltext_path 指向后续阅读片段，完整提取文本另存。
这些检查不是独立进程的内存/CPU 隔离，也不保证从 PDF 恢复排版。

## 4. 保存证据与恢复

目的：支持核查、复现，避免中断后重复下载。

| 产物 | 内容 |
|---|---|
| idea/fulltext/<hash>.pdf | 原始下载文件 |
| idea/fulltext/<hash>.txt | 全部提取文本和页码标记 |
| idea/fulltext/<hash>.reading.txt | 最多 12,000 词的阅读输入 |
| idea/fulltext_records/*.json | 单篇结果、来源 URL、解析版本、哈希、路径、失败原因和提取策略 |
| idea/fulltext_summary.json | 入选数量、可读全文数量、降级数量及逐篇状态 |
| idea/literature.jsonl | 只追加更新 access_level、fulltext_path，保留原始文献与筛选信息 |

每次 step 最多处理一篇或一次重定向。缓存有效时不重新下载；缺少阅读文本时从原 PDF 重建；PDF 哈希不匹配时重新下载。
成功和失败记录都可恢复。网络临时失败在本轮直接降级，不对 PDF 下载做多轮自动重试；新的项目或后续重试入口可重新尝试。
解析实现版本变化时重新提取，避免旧的错误片段一直被缓存复用。

## 5. 运行命令

先做一篇的完整演示，避免一次下载八篇：

```powershell
$fulltextWs = Join-Path $env:TEMP ("air-fulltext-" + [guid]::NewGuid().ToString("N"))
python -u -m scripts.literature.demo --workspace $fulltextWs --fetch-fulltext --read-papers 1 --timeout 180
```

本次实测：13 篇本地候选 → 两批模拟评分 → 1 篇入选 → 真实下载并提取 → phase=read。
其中本地候选元数据来自已有真实论文 fixture，查询规划和评分是模拟，PDF 是从 arXiv 实际下载。

组合选项：

| 参数组合 | 元数据检索 | PDF 获取 | 模型 |
|---|---|---|---|
| 无额外选项 | 本地 fixture | 不下载，保留摘要 | 模拟 |
| --live-retrieval | 真实 API | 不下载，保留摘要 | 模拟 |
| --fetch-fulltext | 本地 fixture | 真实下载入选论文 | 模拟 |
| --live-retrieval --fetch-fulltext | 真实 API | 真实下载入选论文 | 模拟 |
| --replay <批次目录> | 本地回放 | 不下载，保留摘要 | 模拟 |
| --replay <批次目录> --fetch-fulltext | 本地回放 | 明确启用真实 PDF 下载 | 模拟 |

--replay 本身不会联网；加 --fetch-fulltext 则明确允许 PDF 获取阶段联网。回放目录需包含演示查询对应的批次。
正式 IdeaStage() 默认获取 PDF；开发测试通过 fulltext_download=False 关闭网络，演示通过上述命令开关控制。

查看报告、文件和最终文献记录：

```powershell
Get-Content -Encoding UTF8 "$fulltextWs\idea\fulltext_summary.json"
Get-ChildItem "$fulltextWs\idea\fulltext"
Get-Content -Encoding UTF8 "$fulltextWs\idea\literature.jsonl" | ForEach-Object {
    $_ | ConvertFrom-Json
} | Group-Object paper_id | ForEach-Object {
    $_.Group[-1]
} | Where-Object selected_for_reading | Select-Object paper_id, access_level, fulltext_path
```

## 6. 实测与限制

已对 arxiv:2106.09685 验证真实下载、解析及缓存重建。PDF 共 26 页，提取文本按空白统计 13,339 词，阅读片段 5,599 词。
初版章节定位漏掉小型大写标题，只有 265 词；修正后补进正文，相关回归测试已加入。原始 PDF 保持不变。
没有为数字化 PDF 之外的扫描件执行 OCR；加密、损坏、空白或下载失败时保留摘要/元数据并记录原因。
