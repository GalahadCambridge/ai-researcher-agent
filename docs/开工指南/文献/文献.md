## 你负责什么

项目处于 `IdeaDrafting`（起草 idea）时，引擎调用你的阶段。你的输出交给实验和论文同学：

| 文件 | 给谁 | 格式 |
|---|---|---|
| `idea/selected.md` | 实验（生成计划）、论文、GUI（审批页） | 详细设计 2 第 4 节；数据模型 `core/models/idea.py` |
| `idea/literature.jsonl` | 论文（参考文献、引用核验）、GUI | 详细设计 2 第 3.1 节；数据模型 `core/models/literature.py` |
| `idea/search_snapshots/`、`reading_cards/`、`scores.json`、`gap_table.md` | GUI、评价实验 | 详细设计 2 第 3 节 |

## 主干已经做好的（不用重复做）

- **数据模型**：`core/models/literature.py`（`PaperRecord`、`SearchSnapshot`、`ReadingCard`……）和 `core/models/idea.py`（`SelectedIdea`、`IdeaScores`、`parse_selected_md()`）已按详细设计写好。
- **假实现** `airesearcher/stages/fakes/idea.py`：现在流程里用的就是它。**它就是格式样例**——不确定某个文件该长什么样时，打开它生成的文件对照。
- **引用核验服务** `services/literature.py`：`load_papers()`、`verify_citation()`、`bibtex_for()` 已能用，论文同学已经在调用；
  `online=True` 的联网检查已补齐：调用时传入现有项目的 `guard=ctx.permissions.guard`，检查域名及跳转并记录权限事件；未传 guard 时保持离线，在 note 说明未联网检查；实际访问失败返回 `source_unreachable`，未执行检查时保留本地状态并在 note 说明；不调用模型、不修改论文归档。
- **测试替身** `FakeLiterature`：接口和你要写的检索源一样（`search()`、`get()`），数据是 14 篇真实论文，不联网。
- **网络白名单**：`api.semanticscholar.org`、`export.arxiv.org`、`arxiv.org` 已在默认允许列表里。
- **提示注入防护**：`ctx.llm.wrap_untrusted(text, source=paper_id)` 把论文内容包起来再放进提示，网关会告诉模型其中的指令一律不执行。

## 先做这几件事

1. 手动试用两个检索接口（浏览器打开或用 `curl`），确认字段、限速和 BibTeX 的获取方式，补充到详细设计 2 第 5 节：

   ```bash
   curl "https://api.semanticscholar.org/graph/v1/paper/search?query=parameter-efficient+fine-tuning&limit=3&fields=title,year,externalIds,citationStyles"
   ```

2. 建目录 `airesearcher/stages/idea/`，写一个**能被主干找到的空阶段**（第一个 PR 就交这个）：

   ```python
   # airesearcher/stages/idea/stage.py
   from airesearcher.engine.stage import Continue, StageContext, StepResult


   class IdeaStage:
       name = "idea"

       def __init__(self, source=None):
           self.source = source  # 测试时传 FakeLiterature()；None 表示用真实的 Semantic Scholar / arXiv

       def step(self, ctx: StageContext) -> StepResult:
           s = ctx.scratch.setdefault("idea", {})
           phase = s.get("phase", "parse")
           ...
           return Continue("parse 完成")


   def create_stage():
       return IdeaStage()
   ```

   用自己的实现建项目：`air dev new-workspace /tmp/ws --impl idea=real`，然后 `air dev run-stage idea --workspace /tmp/ws`。
3. 先实现 **search**：输入一句研究问题，存下 10~20 篇论文（去重、快照、写 `literature.jsonl`）。
4. 再写第一个提示 `methods_reader.v1`，在 3 篇论文上手动试，调到输出稳定。

## 调用大模型

提示文件放在 `airesearcher/stages/idea/prompts/<名字>.v1.md`，格式照抄 [示例提示](../../../airesearcher/stages/example/prompts/summarize.v1.md)。改提示时新建 `v2` 文件，旧的保留。

```python
out = ctx.llm.complete(role="idea.parse", prompt_id="idea/parse", tier="fast",
                       variables={"goal": ctx.project.goal}, response_schema=IdeaBrief)
brief = out.parsed  # 已按 IdeaBrief 校验过；格式不对时网关会让模型改正
```

便宜的大批量调用（筛选、阅读）用 `tier="fast"`，协调、评分、写作用 `tier="strong"`。

## 测试怎么写

不联网、不花钱：用 `FakeLiterature` 代替真实检索，用 `fake_gateway` 代替真实模型，用 `stages=` 把你的阶段对象直接交给引擎。

```python
# tests/test_idea_stage.py
from airesearcher.core.models.common import ProjectState as S
from airesearcher.core.project import Project
from airesearcher.engine.engine import ProjectEngine
from airesearcher.stages.idea.stage import IdeaStage
from airesearcher.testing.fake_literature import FakeLiterature
from airesearcher.testing.fake_llm import fake_gateway

from .helpers import approve_pending, drive


def test_idea_to_approval(air_home):
    p = Project.create(goal="在每类只有几百条样本时比较 LoRA 和全量微调", task="tasks/smoke", home=air_home)
    llm = fake_gateway(p, {"idea/parse": [{"research_object": "...", "task": "...", "keywords": ["lora"]}]})
    eng = ProjectEngine(p, llm=llm, stages={"idea": IdeaStage(source=FakeLiterature())}, retry_delay=0)
    drive(eng, S.IdeaPending)                      # 一直执行，直到提交了 idea 审批
    approve_pending(p, "changes_requested", "研究问题再具体一点")
    drive(eng, S.IdeaPending)                      # 退回后应生成新版本
```

运行：

```bash
pytest tests/test_idea_stage.py -q
```

看到 `1 passed` 就对了（参数 `air_home` 不用管，写上就行，它让每条测试用独立的临时目录）。

`FakeLiterature` 的几个用法：

- `FakeLiterature(fail_queries={"某条查询"})`：这条查询抛出 `ConnectionError`，用来测重试和换源；
- `src.calls`：记录了每次 `search` 的查询词，可以断言“崩溃重入后没有重复检索”；
- 检索 `"BERT pretraining"` 会同时返回 BERT 的 arXiv 预印本和 NAACL 正式版两条记录，用来测去重；
- 需要固定结果时，在快照文件的 `queries` 里写 `{"查询词": ["paper_id", ...]}`。
