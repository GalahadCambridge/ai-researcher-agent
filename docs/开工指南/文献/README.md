# 文献查阅与选题 Agent 文档

接手时先读 **[交接清单](文献_交接清单.md)**，按其中的安装、免费演示和接口验证命令操作；无需先读完所有开发记录。

## 接手阅读顺序

| 顺序 | 文档 | 用途 |
|---|---|---|
| 1 | [交接清单](文献_交接清单.md) | 当前功能、具体运行命令、输入输出、测试证据、预算与未完成事项 |
| 2 | [原始分工指南](文献.md) | 角色职责、共享接口及开发约定 |
| 3 | [详细设计 2](../../详细设计/2_文献查阅与选题_详细设计.md) | 数据格式、阶段流程及引用核验规范 |
| 4 | [开发与验证工具](../../../scripts/literature/README.md) | 迁移后的免费演示、离线评价和显式付费验证入口 |

软件模块已经实现并提供复现材料。正式人工质量评价尚未完成；A/B 两份事实表均为 AI 草稿，不能作为人工标准答案。LoRA 是验证实例，没有进行真实训练，也没有替实际用户批准研究课题。Windows 运行和测试需使用较短目录，详见交接清单。
