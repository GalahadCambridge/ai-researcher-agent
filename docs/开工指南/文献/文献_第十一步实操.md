# 文献第十一步：交接、评价工具与安全边界验收

> 本文件保留开发阶段记录。当前状态、复现命令和未完成事项请以 [交接清单](文献_交接清单.md) 为准；全部文档见 [文档目录](README.md)。

本轮验收的对象是文献与选题 Agent 软件模块。LoRA 是测试输入，开发者不必批准一个正式研究课题。

## 一、自动接口交接

新增 tests/test_idea_handoff.py，使用真实 IdeaStage 和共享 HTTP/CLI 接口，模型回复使用模拟数据：

- 文献列表和阅读卡可由 GUI 使用的 API 读取，abstract_only 保持可识别。
- 审批详情包含准确版本的英文选题及支持材料。
- 退回生成 v2，旧审批请求不能批准新版本。
- CLI 批准后，下游计划阶段读取获批的准确版本。
- 使用模拟计划阶段仅验证格式与版本交接，不证明实际训练能力。

自动测试发现共享文献详情接口按旧命名查找卡片，无法读取带哈希的 S2/DOI 文件；DOI 的斜杠也会导致路由不匹配。本轮最小修改 airesearcher/server/routes/paper.py：按卡片内部 paper_id 关联，文献详情路径支持含斜杠的标识。没有修改共享模型、引擎、实验阶段或全局模型配置。新增代码注释为英文，原文件其他内容保留。

## 二、离线评价工具

新增 scripts/literature/evaluation.py 与 eval/metrics/literature_compare.py。

- 读取冻结输入、阅读卡和调用日志，计算字段覆盖、引文匹配、token、非缓存调用费用。这里的费用只统计当前工作区的阅读/合成调用；恢复前的已付费历史仍由累计预算账本核算，不能拿此值替代 OpenRouter 总费用。
- 失败/缺失轨迹计入总数，不通过跳过失败提高完成率。
- 比较按原始目标、论文集合和阅读文本哈希分组，检查模型、预算及同组重复的提示版本。缓存回放不能计作独立的真实模型重复。
- 新阅读运行记录 active_seconds：阅读步骤的活动墙钟时间，并发任务重叠只计一次；不包括步骤间等待和恢复时离线时间。历史运行没有测量值时保持 null。
- 人工标准事实缺失时 semantic_accuracy 与 key_information_recall 保持 null，不填造分数。
- --init-gold 生成全部 pending 的模板，隐藏组别、角色和工作区，按不透明 item_id 打散。candidate_text 不是标准答案。
- 人工事实必须包含来源短引文和评审者；工具再次核对冻结文本。字段语义正确性仍由人判断。
- 完整协议要求三个实例、每实例单/多两组各至少两次，完整标注、计时，以及两位独立评审和分歧仲裁记录。小规模试点不能冒充完整实验。

人工规范见 eval/gold/literature/README.md。

## 三、提示注入实验

新增 tests/test_idea_injection.py。把五类指令注入论文摘要：忽略规则、提高预算、执行命令、虚构引用、伪造 system/关闭标签。另用主动返回错误输出的模拟后端验证目标替换和未知指标被阻止，预算/任务/引用受确定性约束。

检查整个流程没有修改 project.yaml、没有工具调用、没有生成计划或执行实验，非法输出最多一次修复后停止。模型均为模拟后端；这些测试验证隔离和校验机制，不证明真实模型面对所有攻击都安全。后续真实语义攻击评价需要受控试点与人工判定。

```powershell
Set-Location D:\study\GitHub\ai-researcher-agent

```

工作区和输出路径必须是新路径。以上模型均为模拟，新增实际 API 费用为零；两组工具能比较不等于实际多角色质量更好。

真实历史产物的免费统计及待标注模板：

```powershell
python -m scripts.literature.evaluation --workspace "$HOME\air\demos\literature-live-recovered-node6-20261020" --output "$HOME\air\demos\real-metrics-new.json"
python -m scripts.literature.evaluation --workspace "$HOME\air\demos\literature-live-recovered-node6-20261020" --init-gold --output "$HOME\air\demos\annotations-new.json"
```

人工完成并仲裁后，通过 --gold <仲裁后的文件> 重新计算。不要把模板中的模型内容复制成事实清单。

## 六、需要人工介入的部分

1. 两名成员先选一篇冻结论文，独立整理 6–8 条关键事实做小试点，再填写盲评和仲裁记录。这是在评价 Agent，不是确定 LoRA 正式选题。
2. GUI/主干成员在自己的实际界面验收文献详情、证据查看和审批/退回。自动 API 测试不代表已与组员当前分支完成合并联调。
3. 正式报告中的准确率、召回率、多角色优劣与实际模型安全性，必须等待对应真实实验和人工判定。当前不编造这些结论。

实际运行材料在个人 air/demos/literature-acceptance-20261020；论文 PDF、模型原始回复、密钥和个人标注不进入代码提交。累计 API 上限仍为 US$2，本轮没有新增付费调用。
