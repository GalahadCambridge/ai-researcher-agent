文档导航：[文献文档目录](README.md) · [开工指南首页](../README.md)。

本文是当前模块的交接入口。交接对象为软件模块：用户提供研究想法，Agent 检索、阅读、提出选题并等待审批。LoRA 是流程验证实例；tasks/smoke 是调试任务，没有进行 LoRA 训练。

## 2. 安装与免费运行

PowerShell，从完整源码仓库运行。Python 需要 3.11 或更高；独立验证使用 Python 3.12。命令中的 python 应指向所创建的虚拟环境。

```powershell
Set-Location D:\study\GitHub\ai-researcher-agent
$env:PYTHONUTF8 = "1"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pip check
```

无需激活虚拟环境。以下命令中的工作区必须是未使用过的新目录；重复运行时更换后缀，不要覆盖历史数据。

```powershell
$handoffDemo = Join-Path $env:USERPROFILE ("air\h-" + (Get-Date -Format "yyyyMMddHHmmss"))
.\.venv\Scripts\python.exe -m scripts.literature.demo --workspace "$handoffDemo\single" --reading-mode single --read-papers 2
.\.venv\Scripts\python.exe -m scripts.literature.demo --workspace "$handoffDemo\multi" --reading-mode multi --read-papers 2
.\.venv\Scripts\python.exe -m airesearcher.cli.main dev check "$handoffDemo\multi" --owner 文献
.\.venv\Scripts\python.exe eval/metrics/literature_compare.py --workspace "$handoffDemo\single" --workspace "$handoffDemo\multi" --output "$handoffDemo\comparison.json"
```

预期两组到 IdeaPending，生成英文选题及待审批记录。默认检索为本地论文样例，所有模型回复为显式模拟数据，费用为零。comparison.json 的人工语义指标为 null，这是缺少人工标签的正常表现。不要把这些运行写成真实模型质量实验。

从完整仓库运行可找到 tasks/、configs/ 等资源。仅复制 airesearcher/ 包，或把普通 wheel 当成包含所有任务资源的完整发行包，不属于本次验证范围。

verify_citation(root, paper_id, online=False) 默认只检查归档。online=True 且传入现有项目的 guard 时，仅有摘要/全文且 URL 非空的记录执行 HTTP 检查；metadata_only 和 not_in_archive 不联网。允许域名由调用方项目权限守卫按 permissions.network.allow 检查；服务不自行读取配置或创建默认权限对象。

本地归档有效且实际联网成功时为 verified；实际发起访问后的 HTTP 错误、超时或异常跳转返回 source_unreachable。未提供项目 guard、权限拒绝、非法协议等导致未执行/未完成检查时，保留本地 verified，并在 note 明确说明未联网核验。先 HEAD，遇 405/501 改用不读取响应体的流式 GET；最多跟随 5 次跳转，每次重新检查域名，设置连接/读超时和请求间总时间预算。服务不修改论文业务归档；联网权限检查必须传入现有项目的 guard=ctx.permissions.guard，通过同一个权限对象和事件日志记录 permission.granted / permission.denied；未传 guard 时不联网、不写事件，并在 note 明确原因。链接可访问并不证明论文结论正确。DOI 或出版商域名若不在白名单，会在 note 明确标记未检查，不会误报成访问失败；服务不会擅自扩大权限。

## 5. 配置、密钥与预算

- reading_mode 为 single 或 multi；limits.read_papers 控制精读数量，reader_concurrency 控制并发。
- 默认生产阶段选择、模型路由及 API 配置沿用主干；demo 显式注入模拟模型。需要真实模型时另安装 .[llm] 并配置模型，不能把 demo 的固定分数用于研究。
- 密钥仅放个人 AIR_HOME/.env 或环境变量，不进入源码、测试数据、文档或 Git。不要通过截图或聊天粘贴密钥。
- 本次收尾不调用付费模型。历史真实试跑使用同一 literature_validation_budget.json 账本，累计 US$2 上限；不能通过更换账本重新获得预算。
- 本文不触发新的付费生成。若以后运行 live.py，需保留同一累计账本并检查剩余预算、当前模型可用性和价格。

## 6. 诚实保留的限制

1. 摘要、提取文本及模型推断的证据等级不同；引文字符串匹配不等于语义正确。
2. 原始目标校验覆盖明确的比较表达，复杂目标可能是 advisory_only，需要实际用户阅读选题。
3. 历史 LoRA 草稿有比较对象偏移，已由后来加入的目标检查发现；原始草稿没有被静默改写，也没有获批。
4. 正式单/多角色质量实验及人工事实核验待完成；上传的 A/B 两份事实表均已确认是 AI 草稿，人工指标不能据此填分。
5. 提示注入测试使用模拟后端，验证的是边界和校验机制，不是所有真实模型攻击的完备防护证明。
6. 项目全局 GUI/CLI 原有中文未做翻译；本模块新增提示词、注释和选题输出为英文。
7. 本模块交接不代表下游真实训练、完整论文或整个小组项目已完成。

原开发过程见文献第一至第十一步实操；正式评价规范见 eval/gold/literature/README.md。

## 9. 组长审查修改（2026-10-21）

### 中断和失败后的人工重试

refine / score / gap_table / revise 共用可恢复的尝试窗口。调用中断或两次尝试失败后，项目暂停并提出问题：retry（可能产生额外模型费用）或 end（结束项目，默认安全选项）。单纯点击继续不能绕过未回答的问题。

用户明确选择 retry 后，追加新窗口，最多再尝试两次。旧尝试、中断标记、回答、历史版本和费用均保留；不会清空预算或绕过验证脚本的 US$2 账本。已经保存完整响应、但尚未来得及写最终回执的调用可直接恢复，不重复调用模型。

后台运行时可通过 GUI 回答，或在另一个终端使用现有 CLI（将 PROJECT_ID 替换为项目编号；不要在真实项目中照抄 retry）：

```powershell
air question PROJECT_ID
# Inspect usage and decide before running either command:
air answer PROJECT_ID retry
# Or end the project without another model call:
air answer PROJECT_ID end
```

本轮用模拟模型验证四个共用步骤的中断/次数用完 → 重启 → 回答重试 → IdeaPending，以及结束不再调用、失败窗口再次重试、保存完整响应后的恢复。初轮恢复专项 14 项通过。没有替真实运行回答重试，也没有发生新增付费调用。

### 交接给调用方的接口

```python
from airesearcher.services.literature import verify_citation

status = verify_citation(ctx.root, paper_id, online=True, guard=ctx.permissions.guard)
```

- 传入当前阶段或 GUI 已持有的项目权限守卫，服务不再自行创建 Project、Events 或 Permissions。无需修改核心日志实现或扩大网络白名单。

### 实现与接口

| 文件 | 作用 |
|---|---|
| airesearcher/stages/idea/scoring.py（新增） | 从冻结材料生成允许引用及带 enum 的提示内 JSON schema；识别截断；恢复已经保存的完整响应 |
| airesearcher/stages/idea/prompts/score.v2.md（新增） | 英文评分提示，提供合法引用、完整五维示例与定向修复；无证据允许空数组并标待核验 |
| airesearcher/stages/idea/selection.py | 默认 v2 每步最多一次生成、每窗口最多两次；解析前归档响应；汇总所有维度的引用错误，并给下一次生成反馈 |
| airesearcher/stages/idea/attempts.py | 暂停问题显示累计与当前窗口次数、最近错误、项目费用；明确 retry 只开新窗口 |
| scripts/literature/recovery.py | 离线复验优先使用独立原始响应；兼容旧 v1 缓存，不产生新模型调用 |
| tests/test_idea_score_recovery.py（新增）、tests/test_idea_selection.py | 验证恢复、窗口追加、严格证据边界、截断与中断、旧提示版本兼容 |

新增产物 idea/selection_rounds/<round>/score_responses/attempt-NNNN.json 保存模型原文、finish_reason、调用 trace 和冻结输入哈希。score_attempts.json 仍是历史尝试与窗口账本，不覆盖旧六次尝试和费用。中断已保存原始响应时可本地恢复；没有响应或调用归档时暂停，不隐式重发。新事件 literature.score_failed 可供日志面板消费。旧 v1 显式固定仍走原 schema 网关路径；新版行为以 v2 为准。

schema 的引用 enum 用于提示约束，本地证据校验仍是最终边界；不是供应商强制结构化输出的保证。未匹配论文、卡片、空引用、弱证据的规则不放松。没有文献支持的上下文评分仍是 to_verify，不等于人工质量评价。共享引擎、预算实现、服务 API、ReadingCard 和其他组员模块没有修改；检索 Error/Wait 与跨调用预算预留仍是独立待解决项。
