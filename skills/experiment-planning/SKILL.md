# Experiment planning rules

Cover each approved hypothesis with an experiment and a comparison. Match sample
sizes, seed sets, tuning budgets and evaluation conditions. Tune on explore
splits only. Respect the task schema and protected files. Use needs_code for
approved methods requiring template changes, without silently substituting a
different method. Define success, failure, resource estimates, replication and
stopping conditions. Return prose in English. Never invent experimental results.
